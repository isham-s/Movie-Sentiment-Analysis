# Movie-Sentiment-Analysis
The project uses text from movie reviews to predict their sentiment. I worked on preparing the text, tokenizing the reviews, training the model, and evaluating its performance.

The model was trained and improved through multiple runs, reaching an accuracy of around 80% after three training runs.

What I Worked On
Text preprocessing
Tokenization
Sentiment classification
Model training
Model evaluation
Testing model performance on movie reviews
Skills

Python, Natural Language Processing (NLP), Machine Learning, Text Preprocessing, Tokenization, Sentiment Analysis, Model Evaluation

Key Learning

The project helped me understand some of the difficulties models can face when working with text, especially when the meaning depends on context, such as negation and sarcasm.
